# Phonebook Application 

This is a full-stack Phonebook application built as part of the Full Stack Open course (Part 3/4). It allows users to view, add, update, and delete contacts.

### Live Application
**You can view the live deployed application here:**  
[Link to Live App](https://phonebook-backend-bwg6.onrender.com)

---

## Tech Stack

**Frontend:**
- React (Vite)
- Axios (for API communication)
- CSS (Vanilla)

**Backend:**
- Node.js
- Express
- MongoDB (Atlas) & Mongoose
- Morgan (Logging)
- CORS

## Features
- **Frontend Validation:** Prevents submission of empty fields.
- **Backend Validation:** Mongoose schemas enforce data integrity (e.g., strict phone number formatting and length requirements).
- **CRUD Operations:** Create, Read, Update, and Delete contacts.
- **Custom Notifications:** Success and error messages guide the user experience.
